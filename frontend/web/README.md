# Website ShareBite
HTML/CSS/JavaScript statis (Bootstrap 5 lewat CDN, butuh internet untuk memuat Bootstrap & font).

```bash
python -m http.server 5500     # lalu buka http://localhost:5500
```
Alamat backend ada di `js/config.js`. Halaman: `index`, `login`, `register`, `catalog`, `food-detail`, `dashboard-donor`, `dashboard-recipient`, `dashboard-admin`, `donations`, `profile`.
